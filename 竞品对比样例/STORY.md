# STORY.md — 竞品对比样例页

## 这一页要回答的问题
「Obsidian / Zotero / ima 已经把该做的都做了，为什么还要自己做一个？」

## 叙事
1. 三条产品各自是某个环节的标杆：Obsidian 组织与关联、Zotero 文献与引文、ima 解析与问答。
2. 但没有任何一款把「入库 → 组织 → 检索 → 溯源」连成一条完整链路；也没有一款把索引交给用户自己掌控。
3. 因此本项目的定位不是「更强的笔记软件」，而是「四库协同 + 可重建索引 + 可复现实验」。
4. 收束：把四段接起来，并且让它可测 —— 这同时是产品空白与课程价值。

## 角色
supporting（论证页），位于项目背景第 2 页，承接「借鉴成熟产品」并过渡到业务功能。
