# DESIGN.md — 竞品对比样例页

## 用途
供《知序 KnowledgeHub》立项/设计稿「01 项目背景」插入的单页竞品对标样例；独立成册便于整页复制进原稿。

## 画布
- 1280 × 720（16:9），安全区 padding：上 44 / 下 36 / 左右 64
- 可用内容宽 1152px

## 配色（源自 KnowledgeHub.pptx 现有版式）
| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主墨 | #1B2A44 | 标题、表格主文字、结论条底色 |
| 辅助 | #667792 | 副标题、说明、图例 |
| 主强调 | #526BEA | 栏目眉标、本项目列头 |
| 辅强调 | #16AE9C | 「具备」符号、结论条高亮 |
| 警示 | #EFA942 | 「部分具备」符号 |
| 弱 | #9AA7BC | 「不具备」符号 |
| 浅底 | #F6F8FC / #EEF2F9 / #E5EAF3 | 维度列底 / 本项目列底 / 行分隔 |

## 字体
Noto Sans CJK SC（与原稿一致）；标题 30 / 栏头 15 / 单元格 13 / 副文 14 / 图例 11。

## 版式映射
- A 区 0–120：眉标 + 论点式标题 + 一句限定语
- B 区 120–620：5 列 × (1 表头 + 6 行) 对比矩阵，本项目列整列浅色底强调
- C 区 620–720：深色结论条（定位句）+ 图例与判定依据

## 密度基线
每格 ≤ 7 字；符号 + 短语，不放整句；全页仅 1 个视觉锚点（深色结论条）。
